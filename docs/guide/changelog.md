# 更新记录

每个版本的完整改动记在这里。应用内「检查更新」的弹窗只放得下三行摘要，要看细节就来这一页。

## v1.0.0

2026-10-14

**首个正式版**。代码内容与 v1.0.0-beta.6 一致，没有新增改动——这一节只说渠道口径的变化，改动清单看下一节。

### 渠道

- **版本号带不带预发布位就是渠道**：`1.0.0` 归正式线，`1.0.0-beta.6` 以及后续带 `-beta.N` 的归测试线。判的是版本号本身，不是发布页上那个「prerelease」勾选——漏勾一次就会把测试包当「最新版」推给正式用户，所以不信它。
- **没手动选过渠道的人，跟着本机装的那一档走**：装的是 Beta 包就继续只收 Beta，装的是正式版就只收正式版。⇒ **测试者不会自动收到 1.0.0**。
- **测试者转正式线**：设置 → 更新渠道 → 选「正式版」，再点「检查更新」。往正式版走不设拦（保守方向不会出错），切回 Beta 会问一次。
- **后续节奏**：正式线的修补按 `1.0.1`、`1.0.2` 递增；想先找人验的改动发 `1.0.1-beta.1`，两条线各自取自己档里最大的那个版本号。

## v1.0.0-beta.6

2026-10-14

### 新增

- **转换方案与报告能整份复制成文本**：任务详情页那颗复制钮交出的是一段带完整字段的纯文本，贴进群或工单就能排查，不必再逐屏截图。分节如下——任务（状态、源包与它的路径、包体积与模组数、创建/开始/结束/耗时）、运行环境（Minecraft 与加载器、Java 需求线与本次实际用的那枚、是否本机安装加载器、内存上限、JVM 参数、启动脚本、`--nogui`、EULA 是自动写入还是要手动接受、是否允许跳过缺件）、服务端设置、保留内容（目录与文件）、转换方案（剔除/保留/新增三档计数、新增模组清单、待人工确认的模组）、产物（输出文件与完整路径、体积与文件数、启动脚本指向、是否并入本机 loader 树、包根写入与沿用了哪些文件、未打包缺件及原因、构建自检的通过/警告/失败）。失败与取消也各有自己一节：出错阶段、报错、详情、已重试几次、还能不能重试；取消会报中断在哪一站、已取件几个、取回多少体积、已取回的文件留在下载缓存可续用。方案快照缺失的老任务不会假装是零——那一行写「N 个（方案快照缺失，未能列出）」。三种语言都覆盖。
- **报错会说清是哪一种网络问题**：连不上下载源、下载超时、被限流这几类分别给出下一动作（「检查网络或代理后重试」vs「稍后再试」），不再统一压成一句"失败"。

### 改动

- **日志改成「模板 + 参数」再按语言渲染**：后端每条日志同时带模板和槽值，界面按当前语言出词 ⇒ 英文界面不再夹中文句子，繁中同步。本机安装加载器那一段的日志也补齐了：下载依赖库、下载服务端本体、安装器就位、退出码与原始输出、安装超时（多少秒、半成品已回收）、安装目录准备失败、装成功但没出 `libraries/`、以及「本机安装完成 · 用时 · 落位」。
- **归一化过的日志行，原句跟着一起复制**：界面上把一长串 URL 收成站点名、把堆栈收成一句话，是为了读；复制出来的文本仍带着改写前的原句，两边不再各说一套。
- **首页那一行不再定高**：详情卡与日志卡那一排从固定高度改成只给下限。窗口一矮，定高容器不会把兄弟往下推、只会溢出叠印，于是失败文案那两行会画到下面的轨道卡上面、按钮排被顶出卡框；现在由内容自己把行撑开。
- **正文宽度的闸门挪了位置**：横向留白改挂在 `.page-scroll` 的 `--pad-x` 上，八页共用一条规则，超宽窗口下正文按 `--page-measure` 收，不必逐页调。
- **关于页把每个外部源的用途写明了**：API 文档、官网、GitHub 加速代理、CurseForge 查询的必经代理、麦块（端信息反查与模组中文简介的出处）、BMCLAPI 各配一句说明，谁可选、谁必经一眼分得开。

### 修正

- **Loader 版本列表没取到时不再骗人**：那颗下拉原来一律显示「待选择」，把"这一档确实没有可用版本"和"根本没取到"混成同一句话。现在取数失败会写成「没取到 · 点开重试」，点开下拉即重取；同时给一条带原因的提示。换 Minecraft 版本会重新拉一趟，且只有最新那一趟的结果能落地，旧请求不会盖掉新答案。
- **窗口最大化/还原那一下内容不再闪**：窗口留白的开关原先在渲染之后才写到 `<html>` 上，而异步 IPC 回来时尺寸已经改完 ⇒ 会先按旧值画一帧（整窗外扩 6px、四角与投影那一圈还挂着），下一帧才收掉。改成布局阶段写入后这一帧不再存在。剩下的一小截是 IPC 往返本身，不去掉就是回到系统动画那 150ms 里等结果。
- **首页「运行日志」卡会随窗口长高**：这一格的高度改成下限沿用旧口径、上限收「滚动口剩下的那一截」，最大化时能多看十几行。日志框换高之后也会贴底——原来只有"来了新行"才回到底部，取消最大化后会停在清单中间那截，得等下一条日志才回来。
- 这一版**刻意没给日志卡加长高动效**：窗口最大化是系统那一下（约 150ms 的矩形动画），任何 300ms 的长高都会拖在它后面，读成"窗口到位了卡片还在爬"。

## v1.0.0-beta.5

2026-10-09

### 新增

- **首页多了「运行日志」一格**：每一站的原始日志都在这一格里。卡头带时间（取末行日志的钟点），右上角能一键复制全部。任务详情页原有的日志面板不受影响。
- **模板改成「撕票根」删除**：模板列表每一行右端是一枚票根。**撕掉不能撤销**，回收站只管任务不管模板；模板编辑页里的删除仍然走原来的确认弹窗。
- **安装与卸载界面重做成向导**：选目录、进度、完成三步收进同一个窗口逐屏往下走，控件放大一档，路径那一行配了「更改」按钮。卸载同改。
- **侧栏图标会动了**：切换页面落定那一下，目标页的图标会逐笔长出来，当作「已经到了这一页」的确认。

### 改动

- **换页不再闪那一下**：新页面的淡入提前收口、上浮照旧走完。原来两条曲线叠在一起，前两百毫秒整屏几乎是空的，读起来像「跳出来」而不是「浮出来」。
- **背景从纯色改成柔和光场**：整窗底上铺了几团随主题走的渐变光，卡片、侧栏、日志卡的材质跟着重调。
- **导航高亮改成一颗滑动的胶囊**：激活底不再每行各画一块，而是一颗常驻胶囊在行间滑过去；激活行的字重与白卡观感一并统一。
- **轨道在没开任务时也如实说话**：解析与检测已经跑完就显示跑完、解析失败就标错，不再一律亮在第一站。
- **进度条按状态上色并带光**：运行沙金、成功翠绿、失败玫瑰。
- **窗口默认高度 800 → 860**：多出来的留白给首页右列那两张卡。
- **回收站长按填充加了波浪边**。
- **设置页收口**：输出目录与工作缓存目录那两格现在是真只读，选目录只走旁边那颗「选择」；两颗「清理」统一成描边加垃圾桶图标，红字只留给「清空全部」。

### 修正

- **同名不同目录的两个包**：包的识别从文件名改成了源文件的绝对路径。把同一个整合包复制一份改内容是最常见的情形，旧口径下后一个包会直接拿前一个包的解析结果与端证据，界面上就是「分类好了，但那数据是上一个包的」。代价是包换了目录或改了名之后会被当成新包，重新解析并重新自动分类一次；磁盘模组索引照常命中，不会重复下载。
- **暗色模式卡顶那条亮带**：磨砂卡撤掉了背景模糊。卡背后本来只有一团不动的光，糊它等于没糊，但糊了会让每张卡按住自己那块底不放——旁边的卡长高把它往下推时，那条带子还在演原来那一段的光。
- **暗色模式页头顶部颜色割裂**：吸顶页头那层纱不再固定到窗口坐标系上，滚动与切主题都不会再错位，也不再需要「切一次主题才恢复」。
- **吸顶页头那条分隔线**：原来会压在卡片顶边、甚至穿过「拖动排序…」那行字；现在把它提进两行之间那段空白里。
- **弹窗列表行左右两侧的投影被切平**：行卡贴到了弹窗内边距。
- **冷启动那一闪**：启动页的方块缺圆角、进度轨道浅到几乎看不见，两处都修了。
- **转换页的下拉菜单被下一张卡切掉半截**：展开时把整条祖先链抬到卡片之上。
- **设置里「下次转换同版本会重新下载安装」**：已删（同版本会复用，不重新下载）。

## v1.0.0-beta.4

2026-10-06

### 新增

- **失败重试不用重下**：转换失败或取消后，已经落位的文件会留在暂存里；重试时先逐个校验，对得上的直接复用，不必把几百 MB 重下一遍。
- **设置里多一类可清理项**：「存储与缓存 → 无用文件」下新增「Loader 安装」一行，显示占用了多少、装着几个版本，可以单独清理（清理它之后，下一次转换同一个加载器版本会重新下载）。
- **卸载入口自愈**：每次启动都会把系统「控制面板 → 程序和功能」里的卸载入口重新指回自绘的卸载向导；官方安装包自带的原生卸载程序被收进 `appdata\nsis-uninstall.exe`，安装目录里只留一个卸载入口。
- **「检查更新」弹窗加了「更新记录」**：按钮在弹窗左下角，点过来到本页并停在当前版本那一节。
- **「需人工确认」徽章会说清被谁按住**：鼠标停在徽章上会显示这一行为什么没被剔除（附属模组是服务端硬依赖、或百科称服务端需要），三处（转换卡、「查看全部」弹窗、构建报告）共用同一句说明。
- **端判定多了几条取数路子**：Modrinth 查不到的模组会拿 jar 里的 modId 反查 CurseForge；CurseForge 单个构建文件没勾端标签时，改从该项目的最新文件集合里兜底；MC百科词条的名字匹配放宽，带别名、副标题、斜杠、括号、驼峰写法的词条现在能对上了。

### 改动

- **百科补全默认改成开**：新装或重置设置后，「平台各腿全答不上」的行现在会去查 MC百科；不想要可以在设置里关掉。
- **只勾一侧端标签不再直接剔除**：原来构建只勾了 Client 就判定服务端不支持、直接删掉；现在改成「另一侧未声明」，落到待人工确认由你决定。
- **jar 里确有服务端代码就不会被删**：扫描到服务端注册项却被判为剔除的模组，现在改成保留，并标「需人工确认」。
- **依据标签改名**：「平台构建 / 平台项目 / 镜像项目」→「Modrinth 构建反查 / 项目声明 / 镜像声明」，名字直说这条结论是从哪儿问出来的。
- **勾选 Aikar's flags 优化参数组时会补起始堆**：`-Xms` 与 `-Xmx` 对齐，超过 12G 换大堆档位；Java 8 那条线改用 `-XX:-UsePerfData`。
- **首页实况显示全量日志**：控制台不再只挑几行。
- **下载预估去掉「精确」说法**：本机安装 Forge / NeoForge 且没命中复用时，预估只表示估计。
- **许可改成 Apache-2.0**：关于页的定位语、免责声明与许可行同步更新。

### 修正

- **缓存目录指向自己的文件夹不会再被删光**：清理和卸载都先认「这个目录是不是本应用盖过归属标记的」，外来目录一条都不动并提示你选错了目录；卸载改成按清单只删自己那几桶与索引、目录收空才撤掉，这种情况下完成页会显示「缓存未清除」。
- **服务端包起不来的几类误删**：被平台声明为 `server_side=optional` 的附属模组（如 GeckoLib）不再被剔掉，客户端前置随硬依赖一起保留（FTB 一类模组受这条影响）。
- **文件名里带 `.part` 的真模组不再被当成半截下载删掉**（例如 `foo.part2.zip`）。
- **卸载后不再残留注册表项**：HKCU 下的产品键与空厂商键会一并清掉；卸载壳留在临时目录的副本和它的浏览器配置延迟自清。
- **下载速率不再乱跳**：切换文件与重试时不会砸回 0。
- **大包不再一条腿吃光查询预算**：百科与 CurseForge 反查各拿独立的墙钟预算，不会被平台腿挤到一行都没问完；取数顺序改为包内文件优先。
- **打包时缺卸载壳会当场报错**：不再静默嵌一个空载荷进主程序。

## v1.0.0-beta.3

2026-10-06

- **应用内一键更新**：发现新版本后，在弹窗里点一下即可完成下载安装 → 校验签名 → 重启升级；签名校验不过不会安装。
- **两个检查入口**：设置里手动检查，或每 24 小时在启动后自动查一次；有可一键安装的新版本时，左下角版本号上出现绿点。
- **跳过这个版本**：被跳过的版本不再提醒，直到出现更新的版本；手动检查仍会正常显示它。
- **下载多来源**：镜像优先、官方兜底，某个来源失败会自动切换。
- **三语使用文档**：本手册站点（简体中文 / English / 繁體中文）。
- 修正：发版工作流收集产物改用独立目录，不再与前端构建产物 `dist/` 撞名。
