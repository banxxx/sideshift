# 更新记录

每个版本的完整改动记在这里。应用内「检查更新」的弹窗只放得下三行摘要，要看细节就来这一页。

## v1.0.0-beta.4

2026-10-06

### 新增

- **失败重试不用重下**：转换失败或取消后，已经落位的文件会留在暂存里；重试时先逐个校验，对得上的直接复用，不必把几百 MB 重下一遍。
- **设置里多一类可清理项**：「存储与缓存 → 无用文件」下新增「Loader 安装」一行，显示占用了多少、装着几个版本，可以单独清理（清理它之后，下一次转换同一个加载器版本会重新下载）。
- **卸载入口自愈**：每次启动都会把系统「控制面板 → 程序和功能」里的卸载入口重新指回自绘的卸载向导；官方安装包自带的原生卸载程序被收进 `appdata\nsis-uninstall.exe`，安装目录里只留一个卸载入口。
- **「检查更新」弹窗加了「更新记录」**：按钮在弹窗左下角，点过来到本页并停在当前版本那一节。
- **「需人工确认」徽章会说清被谁按住**：鼠标停在徽章上会显示这一行为什么没被剔除（附属模组是服务端硬依赖、或百科称服务端需要），三处（转换卡、「查看全部」弹窗、构建报告）共用同一句说明。
- **端判定多了几条取数路子**：Modrinth 查不到的模组会拿 jar 里的 modId 反查 CurseForge；CurseForge 单个构建文件没勾端标签时，改从该项目的最新文件集合里兜底；MC百科词条的名字匹配放宽，带别名、副标题、斜杠、括号、驼峰写法的词条现在能对上了。

### 改动

- **百科补全默认改成开**：新装或重置设置后，「平台各腿全答不上」的行现在会去查 MC百科；不想要可以在设置里关掉。
- **只勾一侧端标签不再直接剔除**：原来构建只勾了 Client 就判定服务端不支持、直接删掉；现在改成「另一侧未声明」，落到待人工确认由你决定。
- **jar 里确有服务端代码就不会被删**：扫描到服务端注册项却被判为剔除的模组，现在改成保留，并标「需人工确认」。
- **依据标签改名**：「平台构建 / 平台项目 / 镜像项目」→「Modrinth 构建反查 / 项目声明 / 镜像声明」，名字直说这条结论是从哪儿问出来的。
- **勾选 Aikar's flags 优化参数组时会补起始堆**：`-Xms` 与 `-Xmx` 对齐，超过 12G 换大堆档位；Java 8 那条线改用 `-XX:-UsePerfData`。
- **首页实况显示全量日志**：控制台不再只挑几行。
- **下载预估去掉「精确」说法**：本机安装 Forge / NeoForge 且没命中复用时，预估只表示估计。
- **许可改成 Apache-2.0**：关于页的定位语、免责声明与许可行同步更新。

### 修正

- **缓存目录指向自己的文件夹不会再被删光**：清理和卸载都先认「这个目录是不是本应用盖过归属标记的」，外来目录一条都不动并提示你选错了目录；卸载改成按清单只删自己那几桶与索引、目录收空才撤掉，这种情况下完成页会显示「缓存未清除」。
- **服务端包起不来的几类误删**：被平台声明为 `server_side=optional` 的附属模组（如 GeckoLib）不再被剔掉，客户端前置随硬依赖一起保留（FTB 一类模组受这条影响）。
- **文件名里带 `.part` 的真模组不再被当成半截下载删掉**（例如 `foo.part2.zip`）。
- **卸载后不再残留注册表项**：HKCU 下的产品键与空厂商键会一并清掉；卸载壳留在临时目录的副本和它的浏览器配置延迟自清。
- **下载速率不再乱跳**：切换文件与重试时不会砸回 0。
- **大包不再一条腿吃光查询预算**：百科与 CurseForge 反查各拿独立的墙钟预算，不会被平台腿挤到一行都没问完；取数顺序改为包内文件优先。
- **打包时缺卸载壳会当场报错**：不再静默嵌一个空载荷进主程序。

## v1.0.0-beta.3

2026-10-06

- **应用内一键更新**：发现新版本后，在弹窗里点一下即可完成下载安装 → 校验签名 → 重启升级；签名校验不过不会安装。
- **两个检查入口**：设置里手动检查，或每 24 小时在启动后自动查一次；有可一键安装的新版本时，左下角版本号上出现绿点。
- **跳过这个版本**：被跳过的版本不再提醒，直到出现更新的版本；手动检查仍会正常显示它。
- **下载多来源**：镜像优先、官方兜底，某个来源失败会自动切换。
- **三语使用文档**：本手册站点（简体中文 / English / 繁體中文）。
- 修正：发版工作流收集产物改用独立目录，不再与前端构建产物 `dist/` 撞名。
