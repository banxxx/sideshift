# 应用更新

## 检查更新

两个入口：

- **手动**：设置 → 外观与关于 → 「检查更新」
- **自动**：每 24 小时在启动后检查一次，发现可一键安装的新版本时，左下角版本号上会出现绿点

## 渠道

默认「跟随当前构建」：你现在用的是带预发布位的版本（如 1.0.0-beta.2），就自动订阅 Beta 线；
纯版本号则订阅正式版。也可以在设置里固定为正式版或 Beta。

## 一键更新

弹窗里点「立即更新」后，应用会依次完成：下载安装包 → 校验签名 → 提示重启。
重启由官方安装器静默完成，**你的设置与任务数据都会保留**。

- 下载有多个来源（镜像优先、官方兜底），失败会自动切换
- 安装包经过签名校验，校验不过不会安装
- 有转换任务在跑时不能安装，等任务结束后再点

## 跳过这个版本

弹窗里可以跳过当前版本：在被跳过的版本之后出现**更新的**版本之前，不再提醒。
手动点「检查更新」仍会正常显示它。

## 更新记录

弹窗里的日志只有几行，写不下全部改动。完整的历史记在 [更新记录](/guide/changelog) 这一页，
弹窗左下角的「更新记录」钮会直接跳到当前这一版。

## 便携版

便携形态暂不支持应用内更新，弹窗会引导到发布页手动下载整包替换。

## 常见问题

- **角标不亮？** 角标只在「发现可一键安装的新版本」时出现；网络不通、发布页缺产物、或你已跳过该版本时不会亮。
- **更新失败了？** 本机版本不受影响。下次启动会提示上一次的安装结果，按提示重试即可。
- **下载很慢？** 下载会自动在多个来源间切换；也可以到发布页手动下载安装包。
