# 快速开始

从选择整合包到拿到服务端包，一共四步。

## 第 1 步：选择整合包

在首页选择要转换的文件。支持三种格式：

- `.mrpack`——Modrinth 整合包
- CurseForge 官方导出的 `.zip`
- 自带 `mods` 目录的普通 `.zip`

## 第 2 步：查看自动分类

应用会自动把每个模组分成三组：

| 分组 | 含义 |
| --- | --- |
| 保留 | 有依据说明服务端需要它 |
| 剔除 | 有依据说明它是客户端专属（如小地图、光影） |
| 待人工确认 | 无法确定去留，默认放在剔除分组并标黄，等你决定 |

每一行都会标出判断依据。不同意的行可以手动改判，**你的选择永远优先于自动结论**。

## 第 3 步：补充模组（可选）

在「从网络添加模组」里搜索 Modrinth 与 CurseForge，把缺失的模组加进方案。
模组详情页会显示它的前置模组，点击即可跳转查看并一并添加。

## 第 4 步：开始构建

确认输出目录与构建选项后开始转换。完成后得到一个服务端压缩包：

1. 解压到服务器目录
2. 同意 EULA（按产物内说明操作）
3. 运行启动脚本，开服联机

## 遇到问题

- 转换页的每一行都标着判断依据与提示，需要你确认的行会明显标出
- 构建失败时，任务详情里会写明原因与建议操作；可修复后重试
