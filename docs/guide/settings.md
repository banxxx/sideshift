# 设置说明

## 路径

| 设置 | 说明 |
| --- | --- |
| 输出目录 | 服务端压缩包的保存位置 |
| 缓存目录 | 下载与构建的临时文件存放位置，可随时清理 |

## 转换

| 设置 | 说明 |
| --- | --- |
| 剔除客户端专属资源 | 自动把纯客户端模组从服务端包中剔除（默认开；关掉即手动模式，只给证据不动方案） |
| 构建后自检 | 完成后对产物做一次离线核对（模组、依赖、配置是否齐） |
| 本机安装 Loader | 为 Forge / NeoForge 产物在本机装出可直接启动的服务端 |
| 复用 Loader 安装 | 同版本重复转换时不再重新下载安装（默认开） |

## 网络

| 设置 | 说明 |
| --- | --- |
| 下载源 | 版本表与加载器的来源：官方 / BMCLAPI 国内镜像 |
| 并发下载数 | 同时下载的线程数（1–16） |
| Modrinth 镜像 | Modrinth 查询优先走 mcimirror 镜像、官方自动兜底（默认开） |
| 联网反查端信息 | 关闭后只靠包内证据与本地缓存分类 |
| 端信息反查源 | Modrinth 官方 / 麦块镜像（国内更快，默认关） |
| 百科补全 | 平台各渠道都查不到时，查 MC百科词条的「运行环境」（默认关） |

CurseForge 的数据始终经镜像获取，**不需要申请 API Key**。

## 应用

| 设置 | 说明 |
| --- | --- |
| 更新渠道 | 跟随当前构建 / 正式版 / Beta（见[应用更新](/guide/update)） |
| 界面语言 | 简体中文 / 繁體中文 / English，切换即时生效 |

::: tip
不确定怎么选时，保持默认即可。所有默认值都按「国内网络 + 解压即用」的场景调过。
:::
