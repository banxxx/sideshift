# 介绍

SideShift 是一款桌面应用，把 Minecraft 模组整合包转换成**开箱即用的服务端包**：
自动判断每个模组是否为服务端所需，补齐启动必需的组件，打包成可以直接上传开服的压缩包。

## 它能做什么

- 读取三种常见整合包格式：
    - `.mrpack`（Modrinth 整合包）
    - CurseForge 官方导出的 `.zip`
    - 自带 `mods` 目录的普通 `.zip`
- 自动判断每个模组在服务端的去留，并给出判断依据
- 从 Modrinth 与 CurseForge 在线搜索并添加模组，无需申请 API Key
- 自动补齐服务端基础组件（如 Fabric API），可按需在本机安装加载器（Forge / NeoForge / Fabric）
- 生成启动脚本与常用服务端配置（EULA、端口、JVM 参数等）
- 应用内检查更新，一键升级

## 适用场景

你下载了一个整合包想和小伙伴联机，但服务端需要的模组列表和客户端不一样——
小地图、光影这类模组在服务端毫无用处，漏装依赖库又会启动失败。
手动挑模组既费时又容易出错，SideShift 替你完成这份筛选与组装工作。

## 它不做什么

- 不修改任何模组本身的内容
- 不是游戏启动器，也不负责替你运行服务端（产物解压后如何开服由你决定）
