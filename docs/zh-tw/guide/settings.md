# 設定說明

## 路徑

| 設定 | 說明 |
| --- | --- |
| 輸出目錄 | 伺服器壓縮包的儲存位置 |
| 快取目錄 | 下載與建置的暫存檔案存放位置，可隨時清理 |

## 轉換

| 設定 | 說明 |
| --- | --- |
| 剔除用戶端專屬資源 | 自動把純用戶端模組從伺服器包中剔除（預設開；關掉即手動模式，只給證據不動方案） |
| 建置後自檢 | 完成後對產物做一次離線核對（模組、依賴、設定是否齊） |
| 本機安裝 Loader | 為 Forge / NeoForge 產物在本機裝出可直接啟動的伺服器 |
| 重用 Loader 安裝 | 同版本重複轉換時不再重新下載安裝（預設開） |

## 網路

| 設定 | 說明 |
| --- | --- |
| 下載來源 | 版本表與載入器的來源：官方 / BMCLAPI 国內鏡像 |
| 並行下載數 | 同時下載的執行緒數（1–16） |
| Modrinth 鏡像 | Modrinth 查詢優先走 mcimirror 鏡像、官方自動兜底（預設開） |
| 聯網反查端資訊 | 關閉後只靠包內證據與本地快取分類 |
| 端資訊反查來源 | Modrinth 官方 / 麥塊鏡像（國內更快，預設關） |
| 百科補全 | 平台各管道都查不到時，查 MC百科詞條的「執行環境」（預設關） |

CurseForge 的資料始終經鏡像取得，**不需要申請 API Key**。

## 應用

| 設定 | 說明 |
| --- | --- |
| 更新頻道 | 跟隨當前建置 / 正式版 / Beta（見[應用程式更新](/zh-tw/guide/update)） |
| 介面語言 | 簡體中文 / 繁體中文 / English，切換即時生效 |

::: tip
不確定怎麼選時，保持預設即可。所有預設值都按「国內網路 + 解壓即用」的場景調過。
:::
