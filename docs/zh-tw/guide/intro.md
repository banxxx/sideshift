# 介紹

SideShift 是一款桌面應用，把 Minecraft 模組整合包轉換成**開箱即用的伺服器包**：
自動判斷每個模組是否為伺服器所需，補齊啟動必需的元件，打包成可以直接上傳開服的壓縮包。

## 它能做什麼

- 讀取三種常見整合包格式：
    - `.mrpack`（Modrinth 整合包）
    - CurseForge 官方匯出的 `.zip`
    - 自帶 `mods` 目錄的普通 `.zip`
- 自動判斷每個模組在伺服器的去留，並給出判斷依據
- 從 Modrinth 與 CurseForge 線上搜尋並新增模組，無需申請 API Key
- 自動補齊伺服器基礎元件（如 Fabric API），可按需在本機安裝載入器（Forge / NeoForge / Fabric）
- 產生啟動腳本與常用伺服器設定（EULA、連接埠、JVM 參數等）
- 應用程式內檢查更新，一鍵升級

## 適用場景

你下載了一個整合包想和小夥伴連線，但伺服器需要的模組清單和用戶端不一樣——
小地圖、光影這類模組在伺服器毫無用處，漏裝依賴庫又會啟動失敗。
手動挑模組既費時又容易出錯，SideShift 替你完成這份篩選與組裝工作。

## 它不做什麼

- 不修改任何模組本身的內容
- 不是遊戲啟動器，也不負責替你執行伺服器（產物解壓後如何開服由你決定）
