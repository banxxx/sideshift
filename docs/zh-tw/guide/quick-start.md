# 快速開始

從選擇整合包到拿到伺服器包，一共四步。

## 第 1 步：選擇整合包

在首頁選擇要轉換的檔案。支援三種格式：

- `.mrpack`——Modrinth 整合包
- CurseForge 官方匯出的 `.zip`
- 自帶 `mods` 目錄的普通 `.zip`

## 第 2 步：查看自動分類

應用會自動把每個模組分成三組：

| 分組 | 含義 |
| --- | --- |
| 保留 | 有依據說明伺服器需要它 |
| 剔除 | 有依據說明它是用戶端專屬（如小地圖、光影） |
| 待人工確認 | 無法確定去留，預設放在剔除分組並標黃，等你決定 |

每一行都會標出判斷依據。不同意的行可以手動改判，**你的選擇永遠優先於自動結論**。

## 第 3 步：補充模組（可選）

在「從網路新增模組」裡搜尋 Modrinth 與 CurseForge，把缺失的模組加進方案。
模組詳情頁會顯示它的前置模組，點擊即可跳轉查看並一併新增。

## 第 4 步：開始建置

確認輸出目錄與建置選項後開始轉換。完成後得到一個伺服器壓縮包：

1. 解壓到伺服器目錄
2. 同意 EULA（按產物內說明操作）
3. 執行啟動腳本，開服連線

## 遇到問題

- 轉換頁的每一行都標著判斷依據與提示，需要你確認的行會明顯標出
- 建置失敗時，工作詳情裡會寫明原因與建議操作；修復後可重試
